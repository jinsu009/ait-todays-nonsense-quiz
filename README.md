## 프로젝트 개요

**오늘의 넌센스 퀴즈**는 매일 새로운 넌센스 퀴즈를 제공하는 사용자 참여형 미니앱 서비스입니다.

사용자는 매일 오전 6시에 공개되는 퀴즈에 참여하고, 오후 8시 이후 정답과 채점 결과를 확인할 수 있습니다.

정답을 맞히고 정해진 시간 내에 결과를 확인하면 누적 정답 횟수가 증가하며, 누적 인정 정답 3회마다 직접 퀴즈를 등록할 기회가 제공됩니다.

사용자가 등록한 문제는 관리자의 검수를 거쳐 출제되며, 이를 통해 사용자 참여 기반의 퀴즈 콘텐츠를 운영하는 것을 목표로 합니다.

## 주요 기능

### 1. 일일 넌센스 퀴즈
- 매일 오전 6시 새로운 퀴즈 공개
- 오후 8시 전까지 주관식 정답 제출 및 수정
- 문제당 힌트 2개 제공
- 오후 8시부터 다음 날 오전 6시 전까지 정답 및 채점 결과 확인

### 2. 사용자 참여 및 통계
- 사용자별 퀴즈 참여 이력 관리
- 누적 인정 정답 횟수 관리
- 총 참여 횟수 및 인정 정답률 제공
- 누적 인정 정답 3회당 문제 등록 기회 지급

### 3. 사용자 문제 등록
- 사용자 직접 넌센스 퀴즈 등록
- 문제, 정답, 힌트 작성
- 등록 문제 검수 상태 조회
- 반려 문제 수정 및 재심사 요청

### 4. 관리자 기능
- 퀴즈 등록 및 출제 일정 관리
- 사용자 등록 문제 승인 및 반려
- 문제 신고 및 차단 관리
- 사용자 참여 현황 및 통계 조회

### 5. 문제 재출제
- 기존 출제 문제 재사용
- 출제 날짜별 참여 기록 분리
- 재출제된 문제의 정답 인정 처리
